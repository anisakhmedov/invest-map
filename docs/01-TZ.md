# InvestMap — Техническое задание

Интерактивная инвестиционная карта: публичный портал + админ-панель + кабинет инвестора/сотрудника.
Языки интерфейса: uz (латиница, основной), uz-кириллица, ru, en.

## Общие требования

- Современные браузеры (последние 2 версии Chrome, Safari, Firefox, Edge); мобильные от 360 px.
- Производительность: LCP < 2.5 с на 4G, карта лениво подгружает слои.
- Безопасность: HTTPS, CSRF/XSS-защита, RBAC на сервере, аудит-лог, резервное копирование БД ежедневно.
- Доступность: WCAG 2.2 AA, версия для слабовидящих.
- Данные хранятся на территории Республики Узбекистан (если требует заказчик — выбрать хостинг в UZ).
