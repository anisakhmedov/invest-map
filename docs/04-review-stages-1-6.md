# Ревью этапов 1–6 (код и безопасность)

Репозиторий пока не под git, поэтому навык `/security-review` (он работает по diff ветки) запустить нельзя.
Ревью выполнено вручную по `apps/web/src`, плюс проверка зависимостей (`pnpm audit --prod`) и поиск
опасных шаблонов (`eval`, сырой SQL, `innerHTML`, секреты в коде).

## Найдено и исправлено

| # | Проблема | Исправление | Проверка |
|---|----------|-------------|----------|
| 1 | Импорт CSV с правом «создавать» мог обновлять существующие объекты | Для строк с существующим slug требуется и право «обновлять» | интеграционный тест |
| 2 | Лимит попыток входа обходился подменой `X-Forwarded-For`; не было лимита на аккаунт | Берётся последний адрес (его добавляет наш прокси); три счётчика: пара 5, адрес 30, аккаунт 15 за 15 минут | интеграционные тесты входа |
| 3 | Память лимитера и журнал неудачных входов росли без границ | Очистка устаревших ключей, потолок 10 000; журнал ограничен теми же счётчиками | юнит-тесты |
| 4 | Postgres и S3 открыты на все сетевые интерфейсы с паролями по умолчанию | Порты привязаны к `127.0.0.1` | `docker compose ps`, тесты |
| 5 | Не было заголовков безопасности | `X-Frame-Options`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`, CSP (`frame-ancestors`, `base-uri`, `form-action`, `object-src`), HSTS в production | юнит-тест, `curl` |
| 6 | Удаление картинки, закреплённой как план, падало необработанной ошибкой | Понятное сообщение, файл сохраняется | интеграционный тест |
| 7 | Удаление территории молча удаляло объекты и лоты | Удаление запрещено, пока в территории есть объекты | интеграционный тест |
| 8 | Таблица объектов молча обрезалась на 5000 строках без порядка | Сортировка по дате и предупреждение | проверка в браузере |
| 9 | Язык из аргумента серверного действия попадал в URL редиректа без проверки | Проверка `hasLocale` | тест выхода с `//evil.example` |
| 10 | GeoJSON с высотой (третья координата) отклонялся целиком | Лишние значения отбрасываются | юнит-тесты |

Дополнительно: файлы из хранилища отдаются потоком (а не целиком в памяти), подписи к картинкам обрезаются
до 200 символов, маскирование секретов в журнале не зависит от регистра ключей.

## Сознательно отложено

- **Выход не отзывает сессию на сервере.** Токен без состояния живёт до 8 часов. Нужен список отозванных
  сессий или таблица сессий; сделаем вместе со сменой пароля и двухфакторной защитой.
- **Редактор карты не предупреждает о несохранённых изменениях** при переключении вкладки.
- **`deepmerge-ts` (high) внутри CLI Prisma.** Только инструменты сборки, данные пользователей через него
  не проходят. Закроется обновлением Prisma.
- **`NEXT_PUBLIC_SITE_URL` по умолчанию `localhost`.** В продакшене обязательно задать, иначе канонические
  ссылки и sitemap будут указывать на localhost.
- **Карта и таблица «Проекты» читают все данные при каждом запросе.** Для тысяч объектов нужен кэш и
  фильтрация на стороне БД.
- **Полный CSP со скриптами** (через nonce) стоит включить на этапе 8, после проверки всех страниц.
