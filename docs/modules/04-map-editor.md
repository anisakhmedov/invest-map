# 04. Редактор карты (админ)
- Рисование и правка полигонов/линий/точек (Terra Draw), привязка вершин, отмена/возврат.
- Управление слоями: порядок, стили, видимость, права на редактирование.
- Импорт/экспорт GeoJSON с валидацией геометрии и SRID.
- Наложение изображения плана (загрузка, позиционирование по 3+ контрольным точкам, прозрачность).
- Дороги и остановки: линии с атрибутами, точки остановок, привязка к дорогам.
- Версионность слоя (история изменений, откат).
**Готово, когда:** заказчик сам нарисовал район, загрузил план и опубликовал на публичной карте.
