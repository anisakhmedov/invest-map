# 02. Контент, медиабиблиотека, настройки сайта
- Страницы и новости: блочный редактор (текст, изображение, галерея, видео, таблица, файл), черновик/публикация.
- Медиабиблиотека: загрузка, папки, alt-тексты на 4 языках, ограничения типов/размера, превью.
- Настройки сайта: название, логотип, favicon, контакты, соцсети, SEO по умолчанию, текст футера, счётчики.
**Готово, когда:** редактор без разработчика публикует страницу на всех языках.
