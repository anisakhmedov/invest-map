# 07. Пользователи, роли, права, журнал
- Роли по умолчанию: SuperAdmin, Admin, Редактор контента, Редактор карты, Менеджер обращений, Инвестор.
- Матрица прав «ресурс × действие» (view/create/update/delete/publish), роли настраиваются.
- Вход: email+пароль (argon2), сброс пароля, блокировка при брутфорсе, опционально 2FA.
- Журнал: кто, когда, IP, действие, было/стало; фильтр и экспорт; неизменяемый.
