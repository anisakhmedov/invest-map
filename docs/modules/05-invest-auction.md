# 05. Инвестиционная таблица и данные аукциона (ручной ввод)
- Таблица проектов/участков: CRUD, массовый импорт CSV/XLSX, экспорт, сортировка, фильтры.
- Поля: название, район, площадь, цена, отрасль, статус, контакты, документы, привязка к геообъекту.
- Аукцион: лоты, даты, стартовая цена, условия, статус, итоги; публикация на портале и карте.
- Валидация, история изменений (аудит).
