# 08. Языки, тема, спец. возможности, SEO
- Языки: uz (lat), uz (кирилл.), ru, en; маршруты /uz /oz /ru /en; fallback и индикатор непереведённого.
- Тема: светлая/тёмная/системная, без мерцания при загрузке.
- Доступность (WCAG 2.2 AA): клавиатура, фокус, ARIA, контраст, режим для слабовидящих (размер шрифта, контраст, отключение анимаций).
- SEO: мета на каждом языке, hreflang, sitemap.xml, robots.txt, Open Graph, JSON-LD, чистые URL.
