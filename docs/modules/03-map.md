# 03. Интерактивная карта, поиск, фильтры, карточки районов
- Слои: области/районы, инвестобъекты, дороги, остановки, планы; включение/выключение слоёв.
- Поиск по названию/кадастровому номеру/району с подсказками.
- Фильтры: тип объекта, отрасль, площадь, стоимость, статус (свободен/занят/аукцион).
- Карточка района/объекта: фото, описание, показатели, таблица, кнопка «Обращение».
- Кластеризация маркеров, URL-состояние (ссылка на вид карты), мобильный bottom-sheet.
**Готово, когда:** 5 000 объектов рендерятся плавно; фильтры работают вместе и сохраняются в URL.
