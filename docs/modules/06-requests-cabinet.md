# 06. Обращения, личный кабинет, задачи, отчёты
- Форма обращения (публичная): тема, объект, файлы, контакты, защита от спама (captcha/ratelimit).
- Статусы: новое → в работе → ответ → закрыто; SLA и уведомления (email).
- Личный кабинет: мои обращения, переписка, избранные объекты.
- Сотрудники: назначение, задачи, дедлайны, комментарии.
- Отчёты: по статусам, районам, срокам; экспорт XLSX/PDF.
