# 01. Публичный портал и адаптивный дизайн
**Цель:** главная, о проекте, новости, контакты, раздел карты; корректно на ПК, планшете, телефоне.
- Брейкпоинты: 360 / 768 / 1024 / 1440. Mobile-first.
- Шапка с переключателем языка и темы, футер, хлебные крошки.
- Главная: hero с мини-картой, ключевые цифры, последние проекты/новости, CTA «Подать обращение».
- Дизайн-токены (цвет, типографика, радиусы) — единый файл; светлая/тёмная схемы.
**Готово, когда:** Lighthouse mobile ≥ 90 (perf/a11y/SEO), нет горизонтального скролла на 360 px.
